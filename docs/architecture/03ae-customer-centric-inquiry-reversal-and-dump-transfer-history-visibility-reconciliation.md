> **`PO-AE1·A` — THE MODEL REVERSAL.**
> - **·A.1** — ***a customer has ONE ongoing Inquiry / sales context;***
> - **·A.2** — ***a customer can have interest in multiple projects simultaneously;***

> - **·B.1** — ***within a tenant, one mobile number = one customer / lead record;***
> - **·B.2** — ***mobile is the duplicate-detection / identity key, immutable, not user-editable, tenant-scoped;***

> **`PO-AE1·C` — REPEAT SUBMISSION.**
> - **·C.1** — ***an active customer resubmitting the SAME project = no new customer / lead / inquiry; the existing interest remains; a system activity records "Customer showed interest again";***
> - **·C.2** — ***a DIFFERENT project = no new customer / lead / inquiry; the project is added to interests; a system activity records "Customer showed interest in another project";***
> - **·C.3** — ***no primary / secondary project terminology; unlimited simultaneous project interests.***
